Welcome

Best practice for code sharing

Code that runs for someone else, not just for you

Much of the code behind published papers is never shared, and what is shared often won’t run. This wiki sets out four steps to take before you submit a paper: make your code Transferable, Available, Documented and Annotated.

The four principles

T Transferable Runs on someone else’s machine.

A Available Archived, with a DOI.

D Documented A README and a licence.

A Annotated Comments that explain the code.
