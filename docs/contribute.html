10 Contribute

This wiki is meant to be added to. If you have a worked example, a language-specific tip, or a correction, here is the whole process.

Copy the page template, write your page, add its filename to _bookdown.yml, run Rscript render.R, and open a pull request. For a small fix, use the Edit this page link in the footer of any chapter instead.

10.1 Make a page

  1. Copy the template.

    cp templates/page-template.Rmd 12-my-page.Rmd

    templates/page-template.Rmd is a working example of everything this wiki uses: the callouts, the R/Python tabs, the before/after blocks, a checklist, and the house style. Write over it.

  2. Start with a level-1 heading and an ID, because other pages link to it:

    # My page {#my-page}

  3. Register the file in _bookdown.yml, in the position you want it to appear. Keep 11-references.Rmd last.

  4. Build and check.

    Rscript render.R

    Open docs/index.html. If you cited anything, add it to 11-references.Rmd, alphabetically by first author.

  5. Open a pull request saying what you added and where it came from.

10.2 The one rule

Separate what the papers say from what you are adding. Cite anything from a source paper by author and year; label your own practical advice wiki guidance, as this wiki does throughout. Keeping the two apart is what makes the wiki trustworthy.
